# TravelX

TravelX is an Expo + TypeScript React Native project. Phase 0 sets up the light design system, reusable UI primitives, navigation shells, and a visual component gallery. Product screens and API logic have not been implemented.

## Run the component gallery

Install dependencies with `npm ci`, then run `npm run web` to preview the gallery in a laptop browser. Run `npm start` to open the project in Expo Go on a phone. Keep the dev server running while testing.

Expo Go compatibility depends on the SDK supported by the installed Expo Go app. The bottom-sheet preview uses `@gorhom/bottom-sheet`; if a target platform requires a development build for this native dependency, use an EAS development build.

## Project structure

```text
src/
  api/                 API module placeholders
  app/                 Expo Router routes and route layouts
  components/          Shared design-system components
  hooks/               Shared hook placeholders
  navigation/          Root, auth, onboarding, and tab shells
  screens/             Feature screen placeholders and gallery
  store/               State placeholder
  theme/               Color, typography, and spacing tokens
  types/               Shared type placeholders
  utils/               Shared utility placeholders
docs/                  Product and implementation planning (01–06)
```

The route source lives in `src/app/` per the repository instructions. Use Expo Router for all navigation. Import shared source through the `@/` alias. Native `ios/` and `android/` projects are generated by Expo and should not be edited by hand.

## Checks

- `npm run check` runs strict TypeScript, ESLint, and Prettier checks.
- `npm run doctor` checks Expo configuration and dependencies.
- `npx expo install --check` checks Expo SDK package alignment.

## Current scope

The planning documents in `docs/` describe the app flow and implementation phases. The approved location scope is Tokyo, Japan and Kozhikode, Kerala, India. Together is a secondary feature; AI is excluded. Phase 0 only includes placeholder routes and the component gallery.
